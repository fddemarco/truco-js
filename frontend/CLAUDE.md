## Conventions

- Use Svelte 5 runes only: `$state`, `$derived`, `$effect`, `$props`. Don't use `export let` or `$:`.
- Event handlers are attributes (`onclick={...}`), not `on:click`.
- Pages fetch data in `onMount`/`$effect` through `api` from `$lib/api/client`. With SSR off, there are no `+page.server.ts` files and no server load functions.
  `const { data, error } = await api.GET("/api/health")`.
  Use `errorMessage(error)` for display.
- If an API type is missing or stale, run `make gen-api`. Don't hand-write API types.
- Read URL state with `page` from `$app/state` and navigate with `goto` from `$app/navigation`.
- Every user-facing string goes through `t("key")` from `$lib/i18n.svelte`. Add the key to both `es` and `en`. Keep game terms (mano, envido, truco, pica-pica, señas...) in Spanish in the English copy.
- Reglamento pages: `lib/rules/es/*.md` is the official text, copied from `docs/reglamento-truco-sepica.md`. `en/*.md` is its translation. Keep both in sync. A new page needs an entry in `SECTIONS` whose title matches the file's `# heading`.
- Card, avatar and seña art is raster, made with an image model from `docs/art-prompts.md`: avatar galleries are cut out and aligned by `tools/art/avatars.py`, final sources go in `../assets/avatars/<character>/` and `../assets/cards/` (workflow and review bar in `docs/art-prompts.md`), then run `pnpm import-art`; never edit the WebPs in `static/` by hand. Suit icons and small UI art are generated: edit `scripts/generate-cards.mjs` and run `pnpm gen-cards`. Use paths from `$lib/cards` and `$lib/avatar/avatar` rather than hard-coding them.
- Tests cover behaviour (logic, rendering, error states), not configuration or content: don't write tests that only check that files, assets or translations exist.
- Style with Tailwind utilities and the shared classes in `app.css`.
- In dev, the Vite server proxies `/api` to `localhost:8000`.
- Log with `log.info("area.what", { ...flat fields })` from `$lib/log`, never sentences. Info and above reach the backend log; API calls are traced with `X-Request-ID` by the client middleware. Use `localStorage["log:level"] = "debug"` for more.

## Commands (from frontend/)

- `pnpm test`: Vitest (jsdom, @testing-library/svelte)
- `pnpm lint`: svelte-check + prettier check
- `pnpm build`: static output in `build/`
- `pnpm gen-cards`: regenerate suit icons, fósforo, favicon and logo in `static/`
- `pnpm import-art [--partial]`: import card/avatar art from `../assets/` (prompts in `docs/art-prompts.md`)
